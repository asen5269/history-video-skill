# 镜头运动与动画配方

避免平面图与文字反复轮播。镜头应展示事件、空间关系、变化或证据细节；纵深、摄影机运动与静止都可服务叙事，不以运动数量判断质量。每镜从下表选一个主配方，写入`shots.json.recipe`；静止镜头说明观看目的。

## 构建纵深：需要视差时至少3层

`parallax-dolly`需要至少3层。其它配方按实际需要分层；史料原图不为凑层数而拆坏文献或画像。单张图的缓慢推进可辅助观看证据，但不能成为全片唯一的叙事手段。

- **前景**：虚化的器物、帘幕、枝叶、烟雾、城垛边缘。与摄影机运动方向相反、位移最大。
- **中景**：主体（人物剪影、建筑、文物、地图主体）。
- **背景**：天空、远山、纸张纹理、暗部渐变。位移最小或不动。
- **氛围层**：体积光、尘埃、雾、雨、烛火闪烁。叠加模式，低透明度，持续微动。

拆层方法：先生成完整场景锁定透视和光线，再用可用的抠图/深度工具拆出2–4层并补被遮挡背景；仅需独立动作的元素以完整场景为参考另出透明素材。未验证工具不声称已完成拆层。史料古画可沿原有结构切层，保留原貌不重绘；画像和文献不为视差损坏内容。最大位移时检查边缘、阴影和露底。

视差比例参考：前景1.6×、中景1×、背景0.3×；摄影机推进时前景同时略放大，产生穿越感。

## 主配方

| recipe | 做法 | 适用 |
|---|---|---|
| `parallax-dolly` | 3–5层2.5D场景，摄影机缓推或横移，前景掠过画面 | 场景建立、氛围 |
| `crane-reveal` | 起于局部特写（屋檐、旗角、手），拉升/后退揭示全景 | 段落开场、转折 |
| `focus-pull` | 前后两层交替虚实，焦点从A转到B，配合台词指向 | 人物关系、对照 |
| `scroll-pan` | 长卷手卷式横向推移，画内元素依次点亮，随台词停驻 | 时间线、行军、长卷古画 |
| `detail-hunt` | 史料原图上摄影机移到细节，其余压暗，细节处圈注/墨线勾勒 | 文献、画像、文物证据 |
| `map-fly` | 真实坐标地图，默认俯视地形晕渲；按叙事沿路线推进或推近地点，路线随行生长、区域高亮，城市落点时停驻；倾斜3D按需使用 | 战役、迁徙、疆域；风格见[地图规范](maps.md) |
| `data-morph` | 数字/账目化为实体（粮袋、银锭、兵符）堆叠增减，镜头跟随变化 | 财政、兵力、人口 |
| `ink-transition` | 水墨晕染/墨滴扩散作为遮罩，从上一镜主体形状长出下一镜 | 段落切换（通常全片≤6次，超出检查是否重复） |
| `match-cut` | 上一镜形状/动作与下一镜对位（烛火→烽火、玉玺→印文） | 时间跳跃、因果 |
| `light-shift` | 同一构图中光源变化（日落、火光逼近、灯灭），环境不变情绪改变 | 命运转折、停顿 |
| `split-time` | 同一地点两个时间并置，擦除线移动对比 | 前后变化 |
| `evidence-hold` | 保持史料、文物或解释图稳定，以overlay标出相关证据，留出阅读时间 | 文献阅读、叙事停顿 |

## 运动规则

- 需要运动时有清楚的起点与落点，对准台词关键词；可用`power2.inOut`/`expo.out`。路线恒速推进等有明确目的的动作可用linear。证据阅读与情绪停顿可以保持镜头静止。
- 主体出场用**被揭示**（被遮挡物让开、光照到、焦点转到、镜头移到），而不是凭空淡入。
- 文字可按叙事需要成为碑文、纸面或地图标签，用可靠排版生成，不让生图捏造原文。解释图标签可保持屏幕平面以便阅读；字幕保持稳定。屏幕大标题仅承担钩子、时间地点、关键概念和结尾问题，不遮挡主体。
- 动态模糊：快速运动开启motion blur（GSAP+CSS filter或Remotion `<Trail>`/逐帧采样），否则运动发硬。
- 景别与配方随信息变化；相邻同景别或同配方须有叙事理由，不机械轮换。长段落应有解释信息的视觉动作，但不按固定30秒强塞地图、文物或数据镜头。

## 自动检查与人工检查

- 不把`fade`、`zoom`、`pan`、`slide`、`ken-burns`当成完整主配方；gate拒绝这些值及未知配方。
- `parallax-dolly`少于3层、其它配方没有素材层，或`detail-hunt`/`evidence-hold`没有`overlay`细节标注层，gate失败。
- 连续两镜同配方、连续三镜同景别、水墨转场超过6次，gate提示人工检查，不自动否定有目的的剪辑。
- recipe、layers、overlay和landing只验证方案描述，不证明实际画面实现。静帧、样片与完整预览仍须实际观看，不能填字段冒充合格。

## 实现要点

HyperFrames：每层一个绝对定位元素，摄影机用父容器的`transform: perspective() translate3d() scale()`统一驱动，GSAP timeline按真实配音时间轴挂关键帧；`translateZ`配合`perspective`得到真实视差。

Remotion：每镜一个`<AbsoluteFill>`场景组件，层按`z`值传入，`useCurrentFrame()`算摄影机位置，各层位移 = 摄影机位移 × 层系数；`interpolate`配`Easing.bezier`。3D地图镜头用`@remotion/three`或预渲染MapLibre倾斜视角帧序列。

静帧样张必须是实际渲染的某一帧，同时导出一段3秒运动样片证明配方生效；只交静帧会掩盖运动问题。
