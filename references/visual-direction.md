# 视觉导演与实际验收

当前默认风格为地图讲解＋插图辅助，以production.md的默认视觉规则为准。下文写实现场、完整场景及背景生图示例仅供用户另行指定风格时参考，不用于当前默认制作。

画面方案阶段先读本文，再读运动配方。先决定观众看见的事件、证据和空间关系，再选素材与动画；recipe不是镜头创意的来源。

## 定调与成本

在工程的 `visual-direction.md` 记录主风格、参考画面及来源、借鉴的具体构图/光线/材质、避免的效果、字幕安全区和素材成本估计。不能仅写“电影感”“高级”；未实际制作的例子不得称为合格样片。

| 可选方向 | 画面组织 | 主要风险 |
|---|---|---|
| 写实历史现场 | 全景建立空间，手部/器物/背影承接行动，细节揭示结果；自然光、可信的时代细节 | 连续宫殿空景，假人物戏 |
| 文物与史料调查 | 文献/文物占主体，光照和细节标注引导观看，地图解释位置 | 纸张纹理成为无关背景 |
| 长卷与历史图解 | 保留古画结构，以克制的线条、地形与实体道具解释关系 | 网页卡片、装饰水墨取代内容 |

按主题选主方向，不机械套用。同片共享色温、黑位、纹理尺度、字体和标注体系；情绪变化可改变光线与对比，统一不等于全片同一滤镜。字幕首先保证移动端可读，不强制透视化。

估算独立场景、人物/道具连续性、拆层补画、视频素材、地图数据与渲染成本。默认10–20分钟不变；若试片显示预算无法支撑目标，提出缩短、分集或降低复杂度的具体取舍，由用户决定。

## 从事件设计镜头

默认地图段先读[地图叙事调度](map-storytelling.md)，优先设计同一地理空间内的事件状态，再决定是否移动镜头或叠加解释；不要把每句口播拆成独立地图重新取景。

每镜在 `textAnchor`、`visualAction`、`assetIds` 外补充以下制作字段：

- `visualRole`：现场 / 证据 / 空间 / 关系 / 情绪，选择主要任务。
- `stateChange`：起始状态→动作或揭示→结束状态；静止证据镜写具体阅读对象。
- `continuity`：与相邻镜的主体、方向、光线或形状关系；不连续时说明跳跃目的。
- `assetMethod`：史料原图 / 完整场景 / 场景拆层 / 解释动画 / 视频素材。

这些字段用于制作与人工验收，当前gate不自动检查其语义。旧工程仅在修改对应镜头时补齐，不因此全片重做。

关掉字幕，观众应能指出哪个对象发生了什么变化，或看见哪项证据。摄影机移动是观看方式，不能替代事件。动作落在对应配音附近，完成后留出阅读/反应时间。剪切依据是信息、行动和情绪变化，不按固定秒数轮换配方。

### 设计示例（非渲染样片）

| 文案任务 | 容易失败的画面 | 可执行方案 |
|---|---|---|
| 军队被困、补给受阻 | 军旗静图持续推进 | 有依据的地图展示地点与阻断关系，再切容器/取水细节；无路线依据时不补画路线 |
| 财政缺口 | 通用账本加飞入数字 | 有依据的收支图揭示缺口，再展示库房空位或催饷文书作为示意；无数量依据时不用按比例堆银锭 |
| 命令引发转折 | 宫殿背景加大标题 | 封闭文书→手部展开→关键内容→后果；原文用可靠排版，生成图不负责造字 |
| 画像或史料分析 | 人像拆成漂浮三层 | 保留原貌，建立完整图，再停驻相关细节并标注；有意静止优于无目的视差 |

重建场景和道具动作属于解释性示意，不是历史影像证据；在工程标记性质与依据，不从生成画面反推史实。缺可靠画像时可用背影、手部、器物、环境或主观视角；人物关系与战役段可按[人物对峙地图](character-map.md)制作明确标记的艺术化立绘，不声称真实相貌复原。

## 素材与空间

优先生成完整构图，锁定地平线、消失点、主体比例、光向、景深与运动余量，再决定是否拆层。拆层要补齐被遮挡背景，检查边缘、阴影与位移后露底。仅需独立动作或遮挡的元素单独生成，并使用该场景作参考；不要每镜默认出三张互不匹配的图。

风格参考负责画风，地点参考负责空间，角色/道具参考负责连续性；一张风格图不能保证全部一致。同地点保持可识别结构和行动方向。参考一致不等于时代准确。

2.5D用于建立空间和引导观看；行走、冲锋、交接等行动需要合适的视频、可控动画或分解剪辑。按需使用有授权实拍或可用视频生成工具，先验证接口、成本与连续性；当前skill没有视频生成脚本，不声称已接入。缺能力时重设计可实现镜头，不用平移人物冒充行走。

按最终16:9构图，依据最大推进/横移预留像素和边缘空间。检查最紧裁切时的主体细节与字幕位置；放大模糊须重出素材或缩小运动，不靠锐化掩盖。独立层检查同一地平线、光向、比例、接触阴影与遮挡关系。

## 代表性试片与验收

同时执行[观众视角验收](audience-review.md)：实际开场与标题兑现单独检查，不能只挑最漂亮或最难的一段证明全片有吸引力；结构、技术与创作判断分别记录。没有观看或试听能力时，标明未完成范围，不预填通过。

试片除检查漂亮与否，还要验证理解：看完能否说清本段谁遇到什么问题、画面展示了什么变化、材料支持什么结论。记录实际看不懂的时间点，再决定改稿、补定位、延长停驻还是减少叠层；不把所有理解问题都归因于观众，也不默认靠加字幕解决。

短试片不能证明10–20分钟的整体节奏。完整预览另查中段信息疲劳、重复解释、人物重新出现的辨识与结尾是否兑现开场。未经真实观众测试，不把制作人员自检写成“观众已理解”。

保留30秒连续试片，选择主要制作难点，而非只挑漂亮开场。若不能覆盖核心现场、解释与转折，在方案阶段说明缺口，并追加仅针对缺口的短运动样片；不凑齐所有载体。扩展全片前解决试片暴露的问题。

在 `visual-review.md` 记录实际观看结果、修正、镜头ID、时间点和真实截图：

| 项目 | 合格依据 | 返工信号 |
|---|---|---|
| 内容 | 素材解释台词，示意与证据性质明确 | 具体事件长期配通用背景 |
| 构图与可读性 | 主次清楚，小尺寸可读，字幕/地名互不遮挡 | 大字遮主体，注意力争夺 |
| 空间与融合 | 透视、尺度、光线、遮挡合理 | 纸片漂浮、露底、阴影错位 |
| 动作与连续性 | 动作有结果，镜头关系清楚，运动有落点 | 只有缩放，无意义换景，动作未完被切 |
| 节奏 | 揭示、阅读、情绪停顿有变化 | 等长轮播，每句转场，持续匀速漂移 |
| 历史可信度 | 衣冠建筑器物有依据，画像保留原貌 | 时代混搭，生成文字冒充原文 |

先正常播放检查音画，再无声看叙事，最后暂停检查构图与合成边缘，另查最大位移时的画面。明显缺陷先修复，不用平均分抵消。未验证能力如实记录，不预填通过。

经用户认可的实际试片可作为后续参考，保留授权、版本与适用范围；未制作时使用上述设计例，不虚构样片库。
